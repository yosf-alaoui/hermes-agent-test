## تفسير الدقة

الأمان وعدم فقدان البيانات أهداف أساسية؛ لا يمكن تقديم ضمان مطلق بانعدام الثغرات أو استحالة الاختراق أو فقدان الملفات. لا يوصف أي إجراء بأنه مكتمل قبل تنفيذه والتحقق منه. وجود المستودع على GitHub وحده لا ينسخ بيانات تشغيل Hermes ولا الملفات غير المتتبعة.

التوسع في الموديل يُفهم مبدئيًا بأنه دعم اختيار مزود أو موديل أكبر دون فقدان البيانات. التدريب أو الضبط الدقيق وتشغيل نماذج محلية يحتاج إلى تحديد الموارد والخصوصية والتكلفة لاحقًا؛ لم يُقرر بعد.
