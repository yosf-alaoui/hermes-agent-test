# خطة التطوير والحماية

هذه خطة عمل، وليست ميزات منفذة.

## المرحلة 0 — التأسيس

- تنزيل المشروع، وتسجيل نسخة الأساس، وإضافة ذاكرة التطوير.
- إثبات اتصال GitHub وصلاحية رفع التحديثات.
- معيار القبول: ملفات التسليم قابلة للقراءة، وcommit منشور ويمكن جلبه من جلسة أخرى.

## المرحلة 1 — الجرد والتشغيل المعزول

- قراءة تعليمات المشروع و`SECURITY.md` وتحديد واجهة التشغيل الأولى ومزود الموديل.
- جرد تخزين الجلسات والذاكرة والمهارات والمرفقات والإعدادات والمهام ومخازن الإضافات لكل ملف شخصي.
- تشغيل في بيئة وملف شخصي معزولين دون المساس ببيانات المستخدم الحالية.
- تحديد حدود الثقة: المستخدم، الموديل، الأدوات، الإضافات، المنصات، والملفات الخارجية.
- معيار القبول: تشغيل أساسي موثق وجرد بمسارات فعلية وفق آليات المشروع الحالية.

## المرحلة 2 — النسخ الاحتياطي والاستعادة

- الاستفادة من آليات Hermes الحالية قبل إضافة أي آلية مكررة.
- استخدام نسخ متسقة لقاعدة SQLite عبر آلية نسخ مناسبة، وتنسيق حفظ بقية الملفات؛ لا يكفي نسخ قاعدة مفتوحة وإهمال WAL.
- نسخ مشفرة خارج الجهاز، ومفتاح استعادة محفوظ منفصلًا، وصلاحيات محدودة، وسياسة احتفاظ وعدم حذف آخر نسخة سليمة.
- التحقق من سلامة النسخ وبناء فهرس محتويات ونسخة مخطط البيانات.
- اختبار الاستعادة إلى موقع معزول والتحقق من الجلسات والذاكرة والمهارات والمرفقات والملفات والمهام.
- تحديد مدة الاحتفاظ وأقصى فقد مقبول للبيانات وزمن الاستعادة مع المستخدم قبل اعتماد الجدولة.
- معيار القبول: تجربة استعادة ناجحة موثقة، تتكرر دوريًا وبعد تغييرات التخزين.

## المرحلة 3 — الحماية والاستقرار

- مراجعة حدود الصلاحيات والأسرار وتنفيذ الأدوات والتعامل مع المحتوى الخارجي وفق `SECURITY.md`.
- التحقق من الاعتماديات وآليات تحديثها، والكتابة الآمنة والتزامن وسلوك التعطل والترحيل.
- اعتماد اختبارات سلوك لكل تغيير جوهري؛ findings الحساسة تتبع سياسة المشروع ولا تُنشر في السجل العام.
- معيار القبول: مخاطر محددة وإصلاحات مثبتة واختبارات مناسبة، دون وصف النظام بأنه غير قابل للاختراق.

## المرحلة 4 — النمو وتبديل النماذج

- توسيع القدرات عبر الآليات الموجودة مثل الإضافات والمهارات، مع إبقاء النواة محدودة.
- تجربة تبديل الموديل والتحقق من استمرار البيانات والمهارات وسلوك الأدوات؛ اختلاف أداء الموديلات متوقع.
- حفظ نسخة قبل أي ترحيل للبيانات، والتحقق من مسار رجوع.
- معيار القبول: انتقال مجرّب بلا فقد بيانات مثبت ضمن نطاق الاختبار.
