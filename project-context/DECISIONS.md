## D006 — 2026-10-09 — نموذج محلي مفتوح قابل للتخصيص

اختار المستخدم قاعدة مفتوحة محلية بحجم 4B أو 8B ثم تخصيصها وتدريبها لاحقًا. اختير Qwen3 4B Instruct للتشغيل الأولي على Intel و16GB RAM، عبر Ollama ومزود Hermes custom. التعريف المحلي `my-agent:4b` إعداد فوق أوزان القاعدة، ولا يُسمى نموذجًا مدربًا خاصًا قبل إنجاز الضبط والتقييم. تفاصيل النسخة والبصمات في `RUNNING.md`.

## D007 — 2026-10-09 — بيانات مستقلة وتشغيل أولي محدود

بيانات التشغيل تحت `$HOME/.local/share/hermes-agent-test` خارج المستودع العام. التشغيل الأولي يستخدم memory/session_search/todo عبر `platform_toolsets.cli`، مع خادم استدلال loopback وإيقاف الإحصاءات الاختيارية. هذا فصل للبيانات وإعداد للقدرات وليس عزلًا لنظام التشغيل. توسيع الأدوات والتدريب والنسخ الخارجية مراحل لاحقة تتطلب تحققًا مستقلًا.

## D008 — 2026-10-09 — ترقية القاعدة إلى Qwen3.5 4B

بعد طلب نموذج أحدث وموافقة المستخدم على الاقتراح، جرى اعتماد `qwen3.5:4b` في تعريف مستقل `my-agent:qwen3.5-4b`، بعد رد فعلي من Ollama وHermes. يحل هذا الاختيار محل قاعدة D006 للتشغيل الافتراضي، دون تغيير قرار استخدام نموذج مفتوح محلي أو نقل البيانات. الأوزان السابقة والتعريف السابق محفوظان؛ أنشئت نقطة استرجاع قبل التعديل. التفكير المطوّل معطل في التشغيل الأولي لتقليل زمن الرد، والسياق الفعلي بقي 65536. الترقية ليست تدريبًا جديدًا أو إثباتًا لتفوق الجودة؛ يلزم تقييم مستقل للعربية والأدوات والذاكرة.

## D010 — 2026-10-09 — تقييم الدارجة قبل ادعاء إتقانها

الشخصية project-assistant تجمع تعليمات دارجة بأمثلة وتعليمات تطوير المشروع، وتحملها المحادثات الجديدة. تحسنت عينة قصيرة، وبقيت أخطاء في عينات أخرى؛ لا يُسمى هذا تدريبًا أو إتقانًا للدارجة. تغيير النموذج أو ضبط الأوزان يحتاج مجموعة أمثلة وتقييمًا أوسع مستقلاً عن نجاح أدوات GitHub.

عقب فشل تجربة أدوات كاملة وبطء البداية، ضُبط التوليد إلى temperature=0.2 وpresence_penalty=0 عبر custom:local-project واختُصرت تعليمات التطوير. نجحت حالة استدعاء GitHub محدودة، لكن جودة التطوير والدارجة تبقى قيد التقييم. مهلة انتظار أطول خاصة بالنموذج المحلي تمنع القطع المبكر؛ لا تُعد تحسين سرعة أو ضمان نجاح.
