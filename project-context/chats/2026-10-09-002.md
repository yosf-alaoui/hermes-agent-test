# الجلسة 002 — إرشادات مصادقة GitHub

التاريخ: 2026-10-09 — America/Toronto.

## طلب المستخدم

> كيف اقوم بالمصادقة لربط حساب github

## الإرشادات المستخلصة

لرفع التغييرات من الجهاز المحلي، تثبيت GitHub CLI عبر `brew install gh` ثم تشغيل `gh auth login --hostname github.com --git-protocol https --web`. اتبع تدفق تسجيل الدخول في المتصفح بحساب يملك صلاحية الكتابة إلى المستودع، ثم `gh auth setup-git` و`gh auth status`. المستخدم ينفذ تسجيل الدخول بنفسه ولا يرسل كلمة مرور أو token إلى المحادثة.

ربط GitHub داخل التطبيق لا يثبت تلقائيًا توفر مصادقة Git على الجهاز. لم يتم تثبيت الأداة أو تنفيذ تسجيل الدخول في هذه الجلسة؛ بانتظار إكمال المستخدم المصادقة. بعد ذلك يجب التحقق من الحساب والصلاحية ثم رفع commit المحلي.

المراجع: https://cli.github.com/manual/gh_auth_login و https://cli.github.com/manual/gh_auth_setup-git
