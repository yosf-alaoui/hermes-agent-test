# الجلسة 003 — تنفيذ مصادقة GitHub

التاريخ: 2026-10-09 — America/Toronto.

## طلب المستخدم

> قم بذالك انت

## التفويض

طلب المستخدم تنفيذ تثبيت GitHub CLI وبدء المصادقة والتحقق ثم رفع تغييرات المشروع المحفوظة. تسجيل دخول الحساب وتفويض OAuth في المتصفح يحتاج إلى تفاعل صاحب الحساب.

## الحالة

- احتاج Homebrew على جهاز Intel إلى بناء الأداة واعتمادياتها؛ أُوقفت محاولة التثبيت وانتُقل إلى ملف GitHub CLI الرسمي الجاهز.
- نُزل `gh` بالإصدار `2.102.0` من إصدارات `cli/cli`، وطابقت بصمته SHA-256 ملف checksums الرسمي.
- ثُبت في `/Users/namdaja/.local/bin/gh` وتحقق تشغيل `gh --version`.
- بدأ تسجيل الدخول عبر المتصفح، مع اختيار مصادقة Git أيضًا، وفُتحت صفحة تسجيل الدخول.
- بانتظار صاحب الحساب ليكمل التفويض في المتصفح؛ لا تُحفظ رموز تسجيل الدخول أو الأسرار في هذا السجل.
- بعد نجاح التفويض، يلزم التحقق من هوية الحساب وصلاحية الكتابة إلى المستودع ثم رفع commits المحلية. لا توجد مصادقة مثبتة أو عملية رفع ناجحة حتى هذه النقطة.
